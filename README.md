# Mosi Bird

A satirical endless runner game built with **Godot 4.5**. Fly through obstacles, avoid political satire-themed pipes, and aim for the high score!

## 🎮 Features

- **Multiple Characters**: Choose from different characters (Mosi, Keju, Rahul, etc.), each with unique obstacle texts.
- **Dynamic Difficulty**: The game gets harder as you score higher!
  - **Level 1**: Normal speed
  - **Level 2**: Faster pipes (Score 10+)
  - **Level 3**: Even faster (Score 20+)
  - **Level 4**: Maximum Overdrive (Score 30+)
- **High Score System**: Your best score is saved locally.
- **Video Cutscenes**: Special video interactions on game over.

## 🕹️ Controls

- **Jump / Fly**: `Spacebar`, `Mouse Click`, or `Touch`
- **Pause**: `P` or `Pause Button` (Escape/Menu on gamepad)

## 🛠️ Project Structure

- `Data/Scenes/`: Contains all game scenes (Main Menu, Gameplay, etc.)
- `Data/Scripts/`: GDScript logic for game mechanics.
- `Data/Sprites/`: Game assets and images.
- `Data/Sounds/`: Audio files for background music and SFX.

## 🚀 How to Run

The game application is included in this folder. Simply run the executable file (e.g., `Mosi_bird.exe`) to start playing!

### 🔧 How to Run in Godot (Source Code)

1. Download **Godot Engine 4.5**.
2. Open Godot and click **Import**.
3. Navigate to the `Data/` folder and select `project.godot`.
4. Click **Run** (Play button) or press `F5` to start the game.
